# ҚМЖ ПЛАТФОРМА — жаңа жоба

Бұл — Next.js негізіндегі әзірлеу нұсқасы. `data/ktp.json` файлында 1–11-сынып КТЖ-ларынан алынған сабақ тақырыптары мен оқу мақсаттары бар. 1-сыныпта 99 жазба сақталған. КТЖ бастапқы DOCX файлдарының кейбірінде кесте құрылымы әртүрлі; сондықтан жариялаудан бұрын әр сыныптың тізімін бастапқы құжатпен салыстырып тексеріңіз.

## Іске қосу
1. Node.js 18.17+ орнатыңыз.
2. Терминалда осы бумаға өтіңіз.
3. `npm install`
4. `npm run dev`
5. `http://localhost:3000` ашыңыз.

## Маңызды шектеулер
Бұл бастапқы әзірлеу нұсқасы. Google OAuth, дерекқорға жеке сақтау, DOCX-ке бастапқы үлгі пішімін сақтап толтыру, PPTX жасау және нақты қозғалысты 3D анимация әлі қосылмаған. ҚМЖ үлгісі бастапқы DOCX файл ретінде пакетке қосылды; оны өзгеріссіз сақтау — келесі әзірлеу кезеңінің талабы.
